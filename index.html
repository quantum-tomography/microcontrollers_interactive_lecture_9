Open-Drain Topology & Wired-AND Bus Logic

Unlike push-pull interfaces (such as SPI or UART), I²C uses open-drain (or open-collector) drivers on both lines: SDA (Serial Data) and SCL (Serial Clock). Devices can only actively pull a line LOW (0V / GND) using an internal N-channel MOSFET. They never actively drive the line HIGH. Instead, external pull-up resistors ($R_p$) connected to $V_{DD}$ passively pull the lines HIGH when all MOSFETs are turned OFF. This prevents bus contention short-circuits when multiple devices share the same two wires.

Module 02 • Synchronization & Packet Structure

Bit-Level Timing, START/STOP Conditions & ACK/NACK

Golden Rule of I²C Data Validity: During normal data transfer, SDA may only change state while SCL is LOW, and must remain stable while SCL is HIGH. The only exceptions are the START (S) and STOP (P) framing conditions, which occur when SDA transitions while SCL is held HIGH.

START Condition (S)

SDA transitions HIGH → LOW while SCL is held HIGH. Claims the bus.

7-Bit Addr + R/W

MSB first (Bits 7..1), followed by 0 = Write or 1 = Read (Bit 0).

9th Clock: ACK / NACK

Transmitter releases SDA; receiver pulls SDA LOW (0) to ACK, or leaves HIGH (1) for NACK.

STOP Condition (P)

SDA transitions LOW → HIGH while SCL is held HIGH. Releases the bus.
